# Figma Design Workflow

Always design before implementation.

Process:
1. Understand the page requirements.
2. Create desktop and mobile layout concepts.
3. Establish reusable design tokens.
4. Define component hierarchy.
5. Create or update Figma frames using Figma MCP.
6. Review typography, spacing, imagery and responsiveness.
7. Obtain explicit design approval.
8. Implement only approved designs.

Never assume a screenshot is an interactive prototype.

Reuse existing Figma components and variables wherever possible.
Do not create duplicate design systems.
