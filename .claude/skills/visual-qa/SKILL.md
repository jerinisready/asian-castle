# Visual QA

Validate the actual running website.

Required viewports:
- Mobile: 375px
- Tablet: 768px
- Desktop: 1440px

Check:
- Horizontal overflow.
- Typography and spacing.
- Image cropping.
- Navigation.
- Mobile menu.
- CTA functionality.
- Gallery interactions.
- Animation behaviour.
- Console errors.
- Accessibility basics.

Capture screenshots for each viewport.

Compare against approved Figma designs.
Report deviations with component names and affected viewport.

Do not silently redesign approved layouts.
